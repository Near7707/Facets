# Facets (한국어)

**Facets**는 캐릭터와 페르소나마다 **옷장**을 만들어 주는 실리태번 확장이에요. 그림("옷")을 여러 벌 넣어 두고, 채팅마다 또는 캐릭터 전체로 갈아입힐 수 있어요.

옷만 있는 게 아니에요. 시간대·장소·계절·다친 모습·나이·그림체도 전부 옷 한 벌처럼 넣을 수 있어요.

## 할 수 있는 것

- **옷 여러 벌 넣기.** 여러 장을 한 번에 고를 수 있고, 이름은 파일 이름으로 들어가요. 나중에 고치면 돼요.
- **누르면 바로 갈아입기.** 아래에서 *이 채팅만* / *캐릭터 전체*를 미리 골라 두고 옷을 누르면 끝이에요.
  - 그 채팅의 모든 메시지 그림이 바뀌어요(옛날 메시지 포함).
  - *캐릭터 전체*는 그 캐릭터의 모든 채팅에 적용되고, 새 채팅도 그 옷으로 시작해요.
- **원래 모습**으로 되돌리기.
- **자르기부터.** 그림을 올리면 한 장씩 자르기 화면이 열려요(*건너뛰기*를 누르면 자동으로 잘라요). 끌어서 옮기고, **축소**하면 상반신까지 담을 수 있어요. 틀 모양은 실리태번 아바타 모양을 따라가요: 원·정사각형·Rounded는 정사각형, Rectangle은 세로 2:3. 채팅에는 자른 그림, 크게 보기에는 원본이 나와요.
- **커플룩.** 캐릭터 옷과 페르소나 옷을 짝지으면 한쪽을 갈아입을 때 짝도 같이 바뀌어요.
- **AI에게 알려주기.** 옷마다 *모습 설명*을 적으면(예: "검은 정장 차림, 머리를 뒤로 넘김") 지금 입은 옷의 설명이 실리태번 확장 프롬프트로 들어가요. 끌 수 있어요.
- **보이는 곳:** 채팅 아바타, 캐릭터 목록(각각 켜고 끄기).
- **백업·가져오기:** 다른 기기로 옮길 때 써요. 그림 파일도 넣을 수 있어요.
- **Facets 데이터 모두 지우기:** Facets가 올린 그림 파일과 Facets 설정을 모두 지워요.
- 영어·한국어 지원. 처음에는 실리태번 언어를 따라가요(한국어면 한국어, 아니면 영어). ⚙ 또는 확장 → Facets에서 바꿀 수 있어요.

## 설치

1. 실리태번 **확장(Extensions)** → **Install extension**
2. `https://github.com/Near7707/Facets` 를 붙여 넣고 설치

## 쓰는 법

- 1:1 채팅 안에서: **마법봉 → 옷장 열기**
- 채팅 없이: **확장 → Facets → 옷장 열기** (옷 정리, 캐릭터 전체 갈아입기만 돼요)
- **옷 정리** → **옷 추가**로 그림을 고르고, 한 장씩 자르거나 건너뛰어요. 중간에 뒤로 가거나 닫으면 남은 그림은 자동으로 잘라서 넣어요. 손잡이를 끌어 순서를 바꾸고, 옷을 누르면 이름·모습 설명·자르기·커플룩·지우기를 할 수 있어요.
- 옷장 안의 ⚙: 보이는 곳, AI에게 알려주기, 언어, 백업, Facets 데이터 모두 지우기, 버전

**팁: 아바타 모양.** 실리태번 채팅 아바타는 작아요. **사용자 설정 → 테마 → 캐릭터 프로필 스타일(Avatars)** 에서 *정사각형*이나 *Rounded*로 하면 *원*보다 그림이 더 많이 보여요. *사각형(Rectangle)*을 쓰면 Facets도 세로 2:3으로 잘라요. 나중에 아바타 모양을 바꾸면 예전 모양으로 자른 그림은 조금 잘려 보일 수 있어요. 그 옷만 다시 자르면 돼요.

## 저장 방식 (건드리지 않는 것)

- 옷 목록·채팅별 선택·커플룩은 **Facets 확장 설정**에만 저장해요.
- 그림은 실리태번 이미지 기능으로 `user/images/Facets_<캐릭터>/` 에 올려요. 올린 파일은 목록에 적어 두고, "Facets 데이터 모두 지우기"는 그 목록에 있는 것만 지워요.
- `window.fetch`를 **가로채지 않아요**. 캐릭터 카드·채팅 파일·채팅 메타데이터에 **아무것도 쓰지 않아요**.
- 캐릭터 이름 변경·삭제, 페르소나 삭제, 채팅 이름 변경·삭제는 실리태번 이벤트를 받아서 따라가요.

## 알려진 한계

- 캐릭터 카드를 내보내도 옷은 따라가지 않아요. Facets 백업으로 옮겨 주세요.
- 그룹 채팅은 아직 지원하지 않아요.
- 채팅을 분기하면, 새 채팅은 "이 채팅만" 선택 없이 시작해요.
- 실리태번 크게 보기의 돋보기(magnifier)를 켜 두면 돋보기 안에는 원래 그림이 보일 수 있어요.
